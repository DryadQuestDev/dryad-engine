### New Features

- **Hotfixes join their release's notes.** A changelog entry for a hotfix (`0.23.1`) no longer stands as a release of its own. Entries sharing `a.b` show as one block in **What's new**, headed by the newest version and date: the release's notes first, then each hotfix under a **Hotfix 0.23.1** heading. `[changes]` shows the whole block, so the description reads **New in 0.23.1** over the release's notes and the fix instead of the fix alone.

### Bug Fixes

- **Editing an encounter on the map keeps its settings.** Saving the map's Edit Encounter popup rebuilt the encounter from its position and image alone, so a collectable lost its type and item and turned into an empty encounter nobody could pick up. Every field the popup does not edit now survives the save.
