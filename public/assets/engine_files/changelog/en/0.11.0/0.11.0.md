### New Features

- **RPG Battler** – A lot of new features, better camera movement, difficulty settings.

### Improvements

- **Game Settings – readable via `getData`** – `game.getData('game_settings')` now returns the merged setting definitions keyed by id, so scripts can read a setting's `values`/options (e.g. to build a custom settings UI) the same way other data files are read.
- A lot of bug fixes

### Breaking Changes
- **Unified `party` action** – `join_party` and `leave_party` are merged into a single `party` action. A bare character id joins, a `!`-prefixed id leaves: `{party: "alice, !bob"}`. Update any scenes still using the old action names.
